One lamp, two lights, two entities

Govee lamps like the Floor Lamp 2 have a main light and a second light (a ring, uplight or ambient strip). Today Home Assistant and Apple Home show one switch for the whole thing. These screens show how Undumb Govee splits it up.

Step 1 · Setup

Paste your Govee API key

Request the key in the Govee app under Profile → Settings → Apply for API Key. It arrives by email within minutes.

The key is checked right away, so a typo shows up here instead of as dead entities later.

Step 2 · Devices

Pick the lamps to add

Every light-type device on the account is listed. The badge shows how many separate lights were detected from what the device reports to Govee.

Step 3 · Optional

Adjust which segments belong to which light

Known models come with a preset. For anything else, the integration splits segments into two lights and you can rename or move them under Configure.

Segments are typed as ranges, like 0-9 or 10-14.

Result · Device page

Three light entities per lamp

Each light can be switched, dimmed and coloured on its own. The whole-lamp entity also carries colour temperature and Govee scenes as effects.

A light made of segments has no power switch of its own, so "off" means brightness 0. Turning it on restores the last level.
