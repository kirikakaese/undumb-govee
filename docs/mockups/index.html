Home Assistant integration · mockups for the H60A4

Square Ceiling Light: main panel and edge ring, as two lights

The Govee H60A4 has a white and colour main panel (RGBWW) and a colour-chasing edge ring (RGBIC). Home Assistant and Apple Home currently show one switch for both. With Undumb Govee each one gets its own entity, and LAN control keeps the main light local.

Edge ring · light.ceiling_light_ring

Step 1 · Setup

API key, plus local control

The cloud key is still needed because Govee only allows ring segments to be controlled through its cloud API.

Power, brightness, colour and colour temperature of the main light go over your network whenever the lamp answers there. That's faster, works when Govee's servers are down and doesn't count against the daily request limit.

Step 3 · Optional

Pick a layout and check the ring

Main light + ring treats the lamp's overall colour as the main panel and its segments as the ring. Switching the ring off leaves the main light on.

If the preset doesn't match your lamp, the undumb_govee.set_segments action paints any segments a test colour so you can see which part of the lamp they are.

Result · Device page

Two light entities

The main light keeps everything the panel can do: dimming, 2700–6500 K white and colour, plus Govee scenes as effects.

The ring is dimmed and coloured through its segments. Because segments have no power switch, "off" means brightness 0.
